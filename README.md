# A Letter for My Love

An interactive, animated love letter built with HTML, CSS, and JavaScript. Designed as a digital storybook with a pink tulip theme.

## Project Structure

```
love-letter/
├── index.html          # Main HTML file
├── css/
│   └── styles.css      # All styling
├── js/
│   └── main.js         # JavaScript functionality
├── assets/
│   └── cute_8bit_loop.mp3  # Background music
└── README.md
```

## Features

- **5-page interactive storybook** with page-turn animations
- **Pink tulips only** - swaying animations, clickable to burst hearts
- **Animated heart** - click to make it pulse
- **Letter that reveals** - text fades in as you scroll
- **Background music** with mute/unmute toggle
- **Mobile responsive** design
- **Floating hearts** background animation
- **Progress dots** showing current page

## Personalization

The letter includes personalized messages about:
- Opening the door with a kiss when husband gets home
- Watching their daughter grow
- "Your asawa 🐣" signature

## How to Use

1. Open `index.html` in any modern browser
2. Click "Open ♥" to start reading
3. Click tulips and hearts for animations
4. Scroll through the love letter
5. Use 🔊 button to mute/unmute music

## Tech Stack

- HTML5
- CSS3 (with flexbox, animations, media queries)
- Vanilla JavaScript
- Google Fonts (Patrick Hand)
- No external dependencies
